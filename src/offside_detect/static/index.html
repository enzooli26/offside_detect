从这里开始

  1. 先体验演示

    无需准备文件。查看合成数据生成的三种事件结果。

  2. 导入自己的素材

    选择视频，以及与该视频匹配的球场标定和传球 / 跟踪 JSON。示例格式在项目 examples 文件夹中；示例标定不能直接用于其他机位。

  3. 生成并复核

    点击生成后查看进度，选择事件查看鸟瞰图和原始画面，下载 MP4 和 JSON 报告。帧号从 0 开始。

当前界面不自动生成标定、传球与跟踪数据。没有逐帧跟踪的片段只显示球场；缺少证据的事件会保留为待复核状态。视频在本机处理，工作文件位于 .local/web-jobs。
