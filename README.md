# offside_detect

面向固定机位球场视频的足球越位辅助检测项目。当前包含中文本地网页工作台、鸟瞰可视化原型和技术调研；自动检测模型和真实视频验证尚未完成。

## 无需终端的使用方式（V005）

在 Windows 资源管理器中双击项目根目录的 **`启动越位分析.vbs`**，工作台会在浏览器打开，不显示终端窗口。本机已具备 Python、OpenCV 和 NumPy，无需增加网页依赖。

1. 点击「体验演示」，可直接查看合成数据生成的三类事件。
2. 使用自己的素材时，选择视频、匹配的球场标定 JSON 和传球 / 跟踪 JSON，点击「生成鸟瞰结果」。
3. 点击事件查看鸟瞰帧和原始画面，下载 MP4 视频与 JSON 报告。
4. 使用完成后点击右上角「关闭工作台」。再次双击启动文件可重新打开。

详见 [V005：网页工作台使用说明](docs/design/02_v005_web_workbench.md)。当前前端接入已有原型，标定与事件文件仍须提供；尚不能只上传视频就自动检测所有传球。素材和生成结果保存在本机 `.local/web-jobs/`，不会纳入 Git 提交。

## 首版设计与原型

- [V004：首版系统设计](docs/design/01_v004_initial_system_design.md)：讨论确认的工作流、模块技术路线、鸟瞰输出与误判边界。
- 原型命令行读取球场标定 JSON 和传球/跟踪 JSON，生成鸟瞰 MP4。JSON 当前由人工或外部检测模块提供，系统尚不自动识别所有传球。

开发者仍可使用 CLI：`python -m pip install -e .` 后运行 `offside-detect --help`；网页服务入口为 `offside-web`。当前要求 Python 3.10+、OpenCV 和 NumPy。
