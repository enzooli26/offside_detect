# V003：论文辅助阅读与翻译工具推荐

核查日期：2026-11-17（北京时间）。本版延续 V002 调研，补充论文阅读工具；不涉及越位检测实现。

## 推荐

推荐使用**沉浸式翻译（Immersive Translate）**，适合阅读英文论文并对照中文译文。

- 官网与下载：<https://immersivetranslate.com/download/>
- 官方使用说明：<https://immersivetranslate.com/docs/usage/>
- 免费 PDF 入口：<https://app.immersivetranslate.com/file/>
- BabelDOC PDF 入口：<https://app.immersivetranslate.com/babel-doc/>

## 与需求的对应关系

用户希望阅读论文时实时翻译。官网说明支持在线及本地 PDF 双语翻译；网页段落可启用鼠标悬停翻译，Windows 默认按住 Ctrl 并悬停段落即可查看双语结果。悬停说明适用于网页，未核验其在所有 PDF 模式中的可用性。

对于在线 PDF，官方步骤为：在浏览器打开文件，点击扩展图标，再点击“翻译 PDF”。本地文件可通过扩展“更多 → 翻译本地 PDF 文件”选择文件。

普通免费 PDF 模式仅支持标准非扫描文档。PDF Pro 支持扫描件、公式识别、逐段双语对照，并可将多栏内容重排为单栏，需要 Pro 会员。官网另提供标为试验功能的 BabelDOC，宣称支持保留排版、公式和复杂布局；这些属于官方功能说明，本次未用论文实测。

## 验证与限制

- 已直接读取官方使用说明，核对上述功能与操作入口。
- “实时”指阅读中发起翻译并查看对照；未测试响应延迟，不保证即时或离线翻译。PDF 解析和翻译可能需要等待。
- 有免费入口，付费功能和解析额度依模式而异；未核验结算价格，不作完全免费或不限量承诺。
- 未安装扩展、登录、付费或上传用户论文，未评测翻译准确率及扫描件处理效果。
- 初次访问 `/zh-Hans/pdf/` 返回“找不到页面”，随后通过该页官方“如何使用”链接进入上述有效说明页。

建议先用一篇公开英文 PDF 试用免费模式，确认双语对照是否符合阅读习惯。
